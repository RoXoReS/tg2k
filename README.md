# tg2k — Автономный Telegram-туннель для Keenetic

### Что это

tg2k — это вырезанная часть оригинального проекта [z2k](https://github.com/necronicle/z2k) (автор: Necronicle).

Из полного установщика z2k были извлечены **только компоненты, отвечающие за работу Telegram-туннеля** (`tg-mtproxy-client`), и полностью удалены все механизмы обхода блокировок (`nfqws2`, стратегии, пробы на 16 КБ и т.д.). 

Такое решение позволяет использовать быстрый и стабильный туннель для Telegram, не вмешиваясь в остальной сетевой трафик роутера и не ломая доступ к «здоровым» IP-адресам.

### Важное ограничение

В данном репозитории лежит бинарник **только для архитектуры ARM64 (aarch64)**. 
Он подходит для современных роутеров Keenetic: **Hero, Ultra, Giga, Hopper** и других моделях на процессорах ARM Cortex-A. 
На старых MIPS-роутерах (Extra, Start, Air) установка не сработает (установщик выдаст ошибку архитектуры).

### Подготовка перед установкой

**1. Компоненты прошивки Keenetic (Netfilter)**
«Модули ядра подсистемы Netfilter» нужны на ЛЮБОЙ прошивке Keenetic — по умолчанию они не предустановлены, и без них туннель не запустится. Их нужно доустановить в веб-интерфейсе Keenetic (раздел «Изменить набор компонентов»):
- «Модули ядра подсистемы Netfilter» — обязательно, на всех прошивках и роутерах.
- «Протокол IPv6» — нужен только на старых прошивках (и только если вы используете IPv6). На новых прошивках IPv6 уже включён по умолчанию, и такого пункта в списке может не быть.
На части прошивок пункт «Модули ядра подсистемы Netfilter» появляется в списке только после того, как выбран компонент «Протокол IPv6».

**2. Подготовка USB и установка Entware (обязательно)**
Подготовьте USB-накопитель и установите Entware по официальной инструкции Keenetic: https://help.keenetic.com/hc/ru/articles/360021214160

После установки Entware выполните обновление индекса пакетов и установите зависимости:
```sh
opkg update
opkg install curl ipset iptables conntrack
```

### Установка

Подключитесь к роутеру по SSH (через встроенный терминал Keenetic или программу вроде PuTTY) и выполните одну команду:

```sh
curl -fsSL https://raw.githubusercontent.com/RoXoReS/tg2k/main/install.sh | sh
```

**Что делает установщик:**

1. Проверяет архитектуру процессора (защита от установки на неподходящие модели).
2. Устанавливает необходимые зависимости (`curl`, `ipset`, `iptables`, `conntrack`) через `opkg`, если их нет.
3. Скачивает файлы туннеля в `/opt/tg-only/`.
4. Настраивает NDM-хук (`90-z2k-tg-redirect.sh`), чтобы Keenetic не сбрасывал правила маршрутизации Telegram при перезагрузках или изменениях сети.

### 🌐 Веб-панель управления (Опционально)

Для удобного управления туннелем без необходимости заходить по SSH, вы можете установить веб-панель.

**Установка панели:**

```sh
curl -fsSL https://raw.githubusercontent.com/RoXoReS/tg2k/main/install-webpanel.sh | sh
```

*(Панель будет доступна по адресу: `http://<IP_РОУТЕРА>:9090`)*

**Возможности панели:**

- Включение/выключение туннеля.
- Смена адреса релея (WebSocket URL) и секрета.
- Просмотр логов и проверка пинга до сервера.

---

### Управление (через SSH)

| Команда | Описание |
| :--- | :--- |
| `/opt/etc/init.d/S98tg-tunnel start` | Запустить туннель |
| `/opt/etc/init.d/S98tg-tunnel stop` | Остановить туннель |
| `/opt/etc/init.d/S98tg-tunnel restart` | Перезапустить туннель |
| `tail -n 30 /tmp/z2k-log/tg-tunnel.log` | Посмотреть последние строки лога |

### Конфигурация

Настройки хранятся в файле `/opt/tg-only/config`.

По умолчанию используются встроенные в бинарник адрес релея и секрет (поэтому в конфиге они закомментированы). Если вы хотите переопределить их (например, при смене сервера), раскомментируйте строки в конфиге и укажите свои значения:

```text
# Z2K_RELAY_URL=ваш_новый_адрес
# Z2K_RELAY_SECRET=ваш_новый_секрет
TG_PROXY_USER_DISABLED=0
```

После изменения конфига обязательно перезапустите туннель:

```sh
/opt/etc/init.d/S98tg-tunnel restart
```

tg2k/
├── install.sh                   # Скрипт установки туннеля

### Удаление

Если вы хотите полностью удалить туннель, веб-панель и все их следы с роутера, выполните:

```sh
curl -fsSL https://raw.githubusercontent.com/RoXoReS/tg2k/main/uninstall.sh | sh
```

*(Скрипт `uninstall.sh` автоматически проверяет наличие веб-панели и удаляет её вместе с туннелем).*

Или выполните команды вручную:

```sh
/opt/etc/init.d/S98tg-tunnel stop
rm -rf /opt/tg-only /opt/zapret2
rm -f /opt/etc/init.d/S98tg-tunnel /opt/etc/ndm/netfilter.d/90-z2k-tg-redirect.sh
rm -f /opt/etc/lighttpd/conf.d/90-tg2k.conf
rm -rf /opt/share/www/tg2k
```
